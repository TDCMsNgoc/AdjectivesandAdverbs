# PHẦN MỀM TRẮC NGHIỆM TIẾNG ANH: ADJECTIVES AND ADVERBS (20 CÂU HỎI)
### TRƯỜNG CAO ĐẲNG CÔNG NGHỆ THỦ ĐỨC (TDC)

Ứng dụng web trắc nghiệm trực quan, hiện đại gồm 20 câu hỏi trọng tâm chuyên đề **Adjectives and Adverbs** (Tính từ và Trạng từ: Vị trí của tính từ và trạng từ, trật tự tính từ OSASCOMP, trạng từ chỉ thể cách, linking verbs + adjective, phân biệt tính từ đuôi -ed/-ing, tính từ/trạng từ bất quy tắc fast/hard/lately...).

## 🌟 ĐẶC ĐIỂM NỔI BẬT THEO YÊU CẦU

1. **Chuẩn 100% 20 câu hỏi theo đề bài yêu cầu**:
   - Trọn bộ 20 câu hỏi kiểm tra đầy đủ các mảng kiến thức:
     1. Trạng từ chỉ thể cách bổ nghĩa cho động từ thường: `easily understand`
     2. Cụm tính từ đi với giới từ: `supportive of`
     3. Tính từ đứng trước bổ nghĩa cho danh từ: `diverse cultures`
     4. Tính từ đứng trước cụm danh từ: `romantic candlelit dinner`
     5. Trạng từ thể cách đứng sau tân ngữ: `pay his employees appropriately`
     6. Danh từ chỉ người sau mạo từ: `As an educator`
     7. Động từ nguyên mẫu chỉ mục đích sau to: `to publicize`
     8. Trạng từ bất quy tắc không có đuôi -ly: `speaks so fast`
     9. Trật tự tính từ OSASCOMP (Age - Origin - Purpose): `a pair of new French sport shoes`
     10. Trật tự tính từ OSASCOMP (Size - Age - Material): `a thick old wooden table`
     11. Linking verb (feel) + tính từ: `felt sleepy`
     12. Linking verb (get) + tính từ: `got quiet`
     13. Linking verb (grow) + so sánh lũy tiến: `more and more angry`
     14. Ngoại động từ hành động + tân ngữ + trạng từ: `sounded the alarm loudly`
     15. Phân biệt trạng từ 'hard' (nỗ lực hết sức) và 'hardly' (hầu như không): `tried hard`
     16. Trạng từ chỉ thời gian thì hiện tại hoàn thành: `Lately, I have started...`
     17. Động từ to be + tính từ chỉ trạng thái: `Is the store open?`
     18. Phân biệt tính từ -ing/-ed & trạng từ chỉ mức độ: `an extremely frightening experience`
     19. Trật tự tính từ OSASCOMP (Opinion - Shape - Color): `disgusting round pink`
     20. Trật tự tính từ OSASCOMP (Opinion - Size - Color): `an amazing enormous blue lake`

## 🌐 HƯỚNG DẪN ĐƯA LÊN GITHUB PAGES & THEO DÕI NGƯỜI ĐĂNG NHẬP

### Bước 1: Tạo Repository trên GitHub
1. Đăng nhập vào [GitHub](https://github.com/) của bạn.
2. Bấm nút **New Repository** (Tạo repo mới).
3. Đặt tên, ví dụ: `tdc-adjectives-adverbs`. Chọn chế độ **Public** và bấm **Create repository**.

### Bước 2: Tải code lên GitHub
Mở PowerShell tại thư mục này và chạy các lệnh:
```powershell
cd "d:\websiteabc\ADJECTIVE AND ADVERBS"
git init
git add .
git commit -m "Initial release of TDC Adjectives and Adverbs Quiz"
git branch -M main
git remote add origin https://github.com/<tai-khoan-cua-ban>/tdc-adjectives-adverbs.git
git push -u origin main
```

### Bước 3: Kích hoạt GitHub Pages (Miễn phí 100%)
1. Vào repository trên GitHub > bấm tab **Settings** (Cài đặt).
2. Ở menu bên trái, chọn mục **Pages**.
3. Tại phần **Branch**, chọn `main` (hoặc `master`) và thư mục `/(root)`, sau đó bấm **Save**.
4. Sau khoảng 1-2 phút, GitHub sẽ cung cấp link trang web công khai có dạng:
   `https://<tai-khoan-cua-ban>.github.io/tdc-adjectives-adverbs/`
5. Gửi đường link này cho sinh viên làm bài thi trên điện thoại, iPad hoặc máy tính!

### Bước 4: Cách Giảng viên theo dõi số lượng người đăng nhập và truy cập link
1. **Xem trực tiếp trên trang web**:
   - Góc trên bên phải thanh điều hướng có huy hiệu `Truy cập: X lượt`.
   - Giảng viên bấm nút **`📊 Thống kê`** để xem tổng số lượt truy cập, danh sách sinh viên đã nộp bài và tải file Excel (CSV).
2. **Xem qua GitHub Traffic Insights (Thống kê chuyên sâu từ máy chủ GitHub)**:
   - Vào Repository trên GitHub > Bấm vào tab **Insights** (ở thanh menu trên cùng của repository).
   - Chọn mục **Traffic** ở cột bên trái.
   - Tại đây GitHub cung cấp biểu đồ chi tiết:
     * **Visitors (Unique visitors)**: Số lượng người dùng độc lập đã truy cập link trong 14 ngày qua.
     * **Views**: Tổng số lượt xem/mở link.
     * **Top referral paths**: Nguồn truy cập từ Zalo, Facebook, Google Classroom, v.v.
